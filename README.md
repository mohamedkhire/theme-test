# Relisys Dark Glassify Theme (v2.0.0)

Next-generation Obsidian & Dark Glassmorphism Theme for **Pterodactyl Panel** and **Blueprint Framework**.

Designed for **Relisys Hosting** by **Mohamed Khire**.

---

## 🌟 Key Features

- **Obsidian Dark Glassify UI**: Deep obsidian surfaces (`#08090e`), frosted glass cards (`backdrop-filter: blur(18px)`), and ambient mesh aura glow.
- **Modern Glass Sidebar Navigation**: Responsive floating sidebar with animated Relisys "R" logo, server context switcher, fast 1-click IP copy with feedback, and subnavigation tabs (Console, Files, Databases, Schedules, Users, Backups, Network, Startup, Settings, Activity).
- **Interactive Theme Studio**: Live client drawer to customize colors (Relisys Cyan, Royal Indigo, Neon Emerald, Cyber Coral, Amethyst, Sunset Amber), frosted blur slider, surface opacity, background modes (Ambient Mesh, Deep Void, Cyber Grid, Custom Wallpaper URL), and haptic audio SFX!
- **Command Palette (`Ctrl+K` / `Cmd+K`)**: Instant keyboard search and jump across all servers and pages.
- **Console & Terminal Enhancements**: macOS 3-dots window header with live session pulse, 1-click log copy, clear console, and distinct glowing power action controls (Start, Restart, Stop, Kill).
- **Semantic Button Styling**: Clean, unified button states with tactile audio feedback and glowing hover effects.
- **Login Page Redesign**: Centered frosted glass card featuring the official Relisys R logo and safe reCAPTCHA clearance.
- **Admin Control Center**: Custom theme management dashboard with live interactive preview card and global defaults.

## 🚀 Installation via Blueprint

On your Pterodactyl server (e.g. Lightsail):

```bash
cd /var/www/pterodactyl
blueprint -remove relisys
rm -f relisys.blueprint
# Upload or download your relisys.blueprint
blueprint -install relisys
```

After installation, clear browser cache or open the panel in an **Incognito window**.
